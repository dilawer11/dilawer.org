At Microsoft, I worked on location-aware systems used in large-scale advertising and ranking pipelines. The work spanned offline data processing, online serving, and infrastructure changes needed to improve both accuracy and cost.

Highlights from this area include improving recall in the location pipeline, shipping an online C++ implementation for delivery logic, and replacing radius-based approaches with reverse geocoding in collaboration with the Bing Maps team.
